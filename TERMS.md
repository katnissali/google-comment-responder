# Terms of Use

Google Comment Responder is provided as a reusable workflow for Codex. It helps Codex scan, draft, reply to, and optionally resolve existing comment threads when the user has the required tool access and document permissions.

Users are responsible for reviewing generated replies, confirming that they have permission to access the target documents, and making sure any posted content is appropriate for their use case. The plugin does not grant access to private documents, bypass permissions, or provide a standalone Google connector.

The plugin is provided as-is, without warranties. Use it at your own discretion and follow the policies that apply to your Codex workspace, Google account, organization, and target documents.

Google product names are used descriptively. Google Comment Responder is not affiliated with or endorsed by Google.
