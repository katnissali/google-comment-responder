# Privacy Policy

Google Comment Responder is a skills-only Codex plugin. It does not include a backend service, database, MCP server, custom OAuth connector, telemetry, or analytics. The plugin itself does not independently collect, store, sell, or share personal data.

When a user runs the plugin, Codex may read or write document comments only through tools, connectors, accounts, and permissions that the user has already authorized in their Codex environment. Access to Google Drive, Docs, Sheets, Slides, and related content is controlled by the user, their organization, Google, and OpenAI/Codex settings.

Users should avoid posting private document contents, credentials, API keys, or confidential links in public support issues.

Support: https://github.com/katnissali/google-comment-responder/issues
