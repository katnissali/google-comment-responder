# Release Notes

Initial public submission of Google Comment Responder.

This skills-only plugin packages a reusable workflow for safely responding to existing Google Drive comment threads. It helps Codex scan comments, filter eligible requests, read surrounding context, draft concise replies, write only to existing threads, avoid deleting comments, resolve only when explicitly asked, and verify writeback.

Reviewer notes:

- Initial submission.
- No MCP server is included.
- No custom Google OAuth connector is included.
- Users must already have Google Drive tools and document permissions available in their environment.
- The plugin contains no private document IDs, credentials, internal company links, or project-specific defaults.
